## ✨ Tính Năng

- 🎮 **3D Hero Section** — 200 particles mạng lưới kết nối, mouse parallax, 4 hình học wireframe xoay
- 🖨️ **12 Sản phẩm** — Máy in, Photocopy, Máy scan, Mực in, Hủy tài liệu
- 🛒 **Giỏ hàng** — LocalStorage, Fly-to-cart animation, mã giảm giá `QUANGLOI10`
- 🔍 **Tìm kiếm trực tiếp** — Live search thông minh
- 📋 **Bộ lọc sản phẩm** — Danh mục, Thương hiệu, Giá, Đánh giá
- 🔄 **3D Product Viewer** — Xoay 360°, zoom, đổi màu vỏ máy real-time
- 📱 **Responsive** — Tối ưu mọi thiết bị

---

## 🎨 Tech Stack

| Công nghệ | Dùng cho |
|-----------|----------|
| **Three.js** | 3D scenes, particle network |
| **GSAP + ScrollTrigger** | Scroll animations |
| **Swiper.js** | Product carousel |
| **AOS** | Animate On Scroll |
| **Tailwind CSS** | Utility classes |
| **Vanilla JS** | Core logic, cart, search |

---

## 🚀 Deploy

Tất cả file tĩnh (HTML/CSS/JS), không cần build:

```bash
# Mở trực tiếp
open index.html

# Hoặc dùng local server
npx serve .
```

## 📁 Cấu Trúc

```
quangloi-ecommerce/
├── index.html              # Trang chủ
├── css/
│   ├── style.css           # Theme chính
│   └── animations.css      # Keyframes
├── js/
│   ├── main.js             # Cart, search, UI
│   ├── three-scene.js      # Three.js 3D
│   └── animations.js       # GSAP
└── pages/
    ├── products.html        # Danh sách sản phẩm
    ├── product-detail.html  # Chi tiết + 3D viewer
    ├── cart.html            # Giỏ hàng
    └── about.html           # Giới thiệu
```
